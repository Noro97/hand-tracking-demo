# Бэклог: в работе и что дальше

Единственный источник правды по «что делать». `STATE.md` отвечает на вопрос
«где мы сейчас», этот файл — «куда идём». Задача уезжает отсюда в
`.tasks/done/NNN-*.md`, когда закрыта.

**Правила ведения**
- Одна строка = одна задача. Есть номер — есть файл в `done/` после закрытия.
- У каждой записи: приоритет, откуда взялась, чем блокирована.
- Не дублировать сюда детали — только ссылка на источник (аудит, роадмап, RETRO).
- Агент, начинающий сессию, берёт первую незаблокированную задачу сверху,
  если пользователь не сказал иное.
