# Hand Tracking Demo

Webcam hand- and face-tracking app built on Vite, React 19 and MediaPipe. Everything runs
**on-device** — no video ever leaves the browser.

Four screens, switchable from the top bar:

| Screen | What it does |
|---|---|
| **BBT Rehab** | Box-and-Block-Test measurement loop: counts one-handed block transfers, tracks duration / smoothness / speed per rep, exports a session as JSON. *This is the product core* — see `docs/STRATEGY.md`. |
| **Face Tracking** | 468-point Face Mesh with live metrics: per-eye blink, mouth opening, smile ratio, head roll. |
| **Hand Filters** | AR filters anchored to hand and face landmarks, plus a "screen" stretched between both hands showing a stylised feed (Poster / ASCII / AnimeGANv2). |
| **Shooting** | Pistol-gesture game: the index finger aims, dropping the thumb onto the fist fires. |

## Run

```bash
npm install
npm run dev            # http://localhost:3000 — grant camera permission
npm run fetch-model    # optional: downloads AnimeGANv2 (8.2 MB) for the Anime AI effect
```

Desktop only (needs a webcam and a wide viewport).

## Commands

```bash
npm run test      # Vitest — 115 tests over the pure logic layer
npm run lint      # ESLint 9, type-aware
npm run build
npx tsc --noEmit
```

## Stack

- Vite 6 + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`) + Tailwind v4
- MediaPipe Hands & Face Mesh, served locally from `public/mediapipe/` (regenerated by `postinstall`)
- AnimeGANv2 via `onnxruntime-web` (WebGPU with a WASM fallback), inference in a Web Worker

## A note on verification

This is a webcam app, and automated/headless environments have no camera. Pure logic
(gesture math, session state, geometry) is covered by tests with synthetic landmark
fixtures; anything involving actual hand or face behaviour has to be checked on a real
camera. Threshold constants shipped so far are starting calibration, not tuned values.
